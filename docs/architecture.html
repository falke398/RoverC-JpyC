Periodic work

All of it runs cooperatively in the Arduino loop() task of each device. Values are the constants in ProjectConfig.h and ControlCore.h.

Timeouts on one axis (0 to 400 ms)

Blue: periods. Amber: slower rates. Red: limits that disarm.

Packet (28 bytes, same layout both ways)

Encoded by control::encode in lib/ControlCore. Radio callbacks only copy bytes into a one-slot mailbox; nothing else happens in the callback.

    Why the system disarms

    Fault codes

    Bus and Configuration faults latch until reboot. Link and LocalStop clear after a fresh deliberate arm.
